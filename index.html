Question 5: Electricity Bill Calculator

Take the number of electricity units consumed and calculate the bill using these rates: - First 100 units: Rs. 10 per unit - Next 100 units: Rs. 15 per unit - Above 200 units: Rs. 20 per unit 


        let unit = Number(prompt("Enter electricity bill unit"))

        if (unit <= 100) {
          console.log("bill is " + (unit * 10))
        }
        else if (unit > 100 && unit <= 200) {
          console.log("bill is " + (100 * 10 + (unit - 100) * 15))
        } 
        else {
          console.log("bill is " + (100*10 + 100*15 +(unit - 200) *20))
        }
